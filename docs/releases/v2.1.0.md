## Local server controls

Discover TCP listeners owned by your account, save a launch command, pin a server,
and start, stop or restart it from the **Local servers** dashboard. macOS also has
pinned controls in its menu bar; the Windows tray opens the browser controls.

Windows configuration asks for the working folder. **Windows Stop ends the process
immediately, so unsaved work can be lost.** macOS Stop sends SIGTERM. Actions require
confirmation and revalidate the selected process. A command is reported started
only after its listener is verified at the saved port; a timeout never force-kills it.
Saved commands remain private and are excluded from device sharing. Linux retains
the browser dashboard, with local server controls marked unsupported.

## Upgrade

Quit the native app and wait for its ledger save, then install the new download.
Existing usage history and preferences are retained. **No rebuild is needed**;
archived history remains in the durable ledger during supported migrations.
Local server controls do not change the telemetry schema.
